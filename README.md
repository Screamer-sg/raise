# Raisecom Configurator v7.2 Lite Visual

Raisecom Configurator v7.2 Lite Visual — це офлайн веб-додаток для створення, редагування, перевірки та експорту конфігурацій комутаторів Raisecom. Проєкт складається з легкого фронтенду на React 18 (через CDN) і бекенду на Flask 3 з Python 3.11.

## Можливості

- ручне створення профілів та імпорт із CSV;
- конвертація конфігурацій між моделями;
- автоматична перевірка налаштувань перед експортом;
- збереження профілів у локальному JSON-сховищі та їх щоденне резервне копіювання;
- відображення карти портів із кольоровими індикаторами режимів;
- формування CLI-скриптів, `.cfg` та `.json` файлів;
- експериментальне підключення до обладнання через Telnet або Serial.

## Структура проєкту

```
backend/            # Flask застосунок та бізнес-логіка
frontend/           # Мінімалістичний React-інтерфейс (CDN)
storage/            # JSON-файли з профілями, шаблонами та резервними копіями
install.sh          # Встановлення залежностей (venv)
run.sh              # Запуск бекенду Flask
requirements.txt    # Python-залежності
```

## Швидкий старт

```bash
./install.sh
./run.sh
```

Після запуску бекенд доступний за `http://localhost:5000/`. На головній сторінці завантажується React UI, який працює з REST API.

## API огляд

Основні ендпоїнти доступні за `/api/*`:

- `GET /api/configs` — список профілів.
- `POST /api/configs` — створення нового профілю.
- `PUT /api/configs/<id>` та `DELETE /api/configs/<id>` — редагування й видалення.
- `POST /api/import/csv` — імпорт конфігурацій із CSV.
- `POST /api/convert` — конвертація профілю для іншої моделі.
- `POST /api/validate` — перевірка налаштувань.
- `GET /api/configs/<id>/export?format=cli|cfg|json` — експорт у потрібному форматі.
- `GET /api/configs/<id>/ports` — отримання карти портів.
- `POST /api/connections/telnet` та `/serial` — пробне підключення до обладнання.
- `GET /api/backups` та `POST /api/backups/run` — робота з резервними копіями.

## CSV формат

Файл повинен містити колонки:

```
name,model,hostname,port,mode,vlans,description
```

Кожен рядок описує порт, рядки з однаковими `name+model+hostname` формують один профіль.

## Резервне копіювання

Бекенд запускає фонового воркера, який раз на 24 години зберігає копію `storage/profiles.json` у каталозі `storage/backups/`. Додатково можна викликати ручний бекап через `POST /api/backups/run`.
